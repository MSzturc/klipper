# THEOS Klipper Fork

A fork of [Klipper](https://www.klipper3d.org/) maintained by Matt The Printing Nerd, bundling additional features used by the [THEOS](https://github.com/MSzturc/THEOS) printer operating system on top of stock Klipper.

The core Klipper experience is unchanged: if you already run Klipper, everything you know still applies. Stock documentation at [klipper3d.org](https://www.klipper3d.org/) remains authoritative for installation, kinematics, tuning, and everything not listed below.

## Fork-specific features

- [**Sensorless Homing**](sensorless_homing.md) — StallGuard-based homing with per-rail `home_current`, `min_home_dist`, and `homing_accel`; guaranteed post-home current restore; multi-stepper-per-rail current swap. Based on work by Brandon Nance, Bea Nance, Rogerio Goncalves, and Zeanon on Kalico, re-derived on the current Klipper base.
- [**`RESET_VELOCITY_LIMIT` G-code**](reset_velocity_limit.md) — restores `max_velocity`, `max_accel`, `square_corner_velocity`, and `minimum_cruise_ratio` to their configured values in one call, undoing any runtime `SET_VELOCITY_LIMIT` / `M204` override. Based on Kalico PR #472 by Matt Szturc.
- [**TMC Drivers**](tmc_drivers.md) — motor-data-driven autotuning of chopper/PWM/hysteresis/StallGuard/CoolStep, per-stepper low-noise homing profile, TMC5160 driver_cs and short_conf, TMC2240 driver_cs / current_range / mandatory rref, mandatory sense_resistor, stepstick lookup table. Combines Klipper3d PR #6644 (Honest Brothers), Kalico PRs #382/#444/#525/#556/#613, and original autotuning work.
- [**ConfigParser Extensions**](configparser_extensions.md) — variable interpolation (`${section.option}`), arithmetic evaluation with `min`/`max`/`abs`/`round`, default values (`:default`, `:None`), printer.cfg-overrides-sub-configs semantics, conditional includes, variable references in `[include]` paths, recursive subfolder globs, escape syntax (`\${literal}`), and the `RELOAD_GCODE_MACROS` G-code. Based on Kalico PRs #448/#482/#753 by Frank Tackitt and original work by Matt Szturc.
- [**Fan Control**](fan_control.md) — `min_power` duty floor and `power` status key for actual PWM duty; `initial_speed` for at-startup fan command; `control: curve` for `[temperature_fan]` with point-list interpolation and heating/cooling hysteresis; optional short `id:` alias for `SET_FAN_SPEED` on `[fan_generic]`; hardware-PWM shutdown handling and kick-start last-value reset. Based on Kalico PRs #44/#193/#433/#436/#466/#819 by Kubaracek, Zeanon, Frédéric Beaucamp, NokkOnEffect, and Rogerio Goncalves, plus original work by Matt Szturc.
- [**PID Autotune (Adaptive Relay)**](heater-pid-autotune.md) — `PID_CALIBRATE` rewritten on the Taysom & Sorensen iterative method with amplitude-based convergence and a verification heat-up; better suited to high-thermal-mass beds and chamber heaters than the stock single-cycle Åström-Hägglund tune. Based on Kalico PR #62 by Dan Sorensen.
- [**Velocity-Form PID**](heater-pid-velocity.md) — `control: pid_v` selects a velocity-form PID alternative to the positional controller, with `SET_HEATER_PID` for runtime Kp/Ki/Kd retuning on either algorithm. Based on Kalico PR #47 by Dans98 and PRs #35/#98 for the `SET_HEATER_PID` command.
- [**PID Profiles**](heater-pid-profiles.md) — per-heater named profiles for PID/PID-velocity/dual-loop gains and `smooth_time`, with `PID_PROFILE LOAD/SAVE/REMOVE`, profile-aware `PID_CALIBRATE`, and `SET_SMOOTH_TIME`. Based on Kalico PR #162 by Vladimir Vukicevic with follow-up fixes by Tomas Petrlik.
- [**Dual-Loop PID**](heater-dual-loop-pid.md) — `control: dual_loop_pid` cascades an outer (load) loop into an inner (element) loop with a hard `inner_max_temp` ceiling, two-pass calibration via `PID_CALIBRATE`. Based on Kalico PR #735 by Zeanon with follow-up fixes in PRs #758 / #809.
- [**Model Predictive Control (MPC)**](heater-mpc.md) — `control: mpc` model-predictive heater controller with `MPC_CALIBRATE` and live `MPC_SET` tuning, fan-tracking via `fan_ambient_transfer` breakpoints, filament-cooling load with `filament_diameter`/`density`/`heat_capacity`, virtual `mpc_block_temperature` and `mpc_ambient_temperature` sensors. Based on Lasse Dalegaard's Klipper-MPC implementation with calibration, live-tuning, and virtual-sensor extensions from Kalico PRs #447/#468/#517/#555/#708/#732/#775/#819.
- [**Cold Extrude**](heater-cold-extrude.md) — Marlin-compatible `M302` and Klipper-native `COLD_EXTRUDE` for runtime override of `min_extrude_temp`, with a session-only enable flag and a persisted threshold update. Based on Kalico PR #750 by Zeanon, with the dual-sensor heater follow-up in PR #766.
- [**Heater Diagnostics**](heater-diagnostics.md) — ADC out-of-range shutdowns now name the offending heater and report its `last_temp` against the configured `min_temp`/`max_temp`; `PrinterHeaters.lookup_heater` accepts the full section name as shorthand. Based on Kalico PRs #182 and #252 by Rogerio Goncalves.
- [**BDSensor**](bdsensor.md) — in-tree integration of the contactless inductive bed-distance probe; `[BDsensor]` config section, `BDSENSOR_*` G-code commands, automatic firmware build (`src-y += BD_sensor.c`), and `[board_pins]` alias resolution on `sda_pin` / `scl_pin` / `endstop_pin`. Based on work by Mark Yue, integrated from upstream `new` branch HEAD `8d0f833`.
- [**`use_probe_xy_offsets` Config Key**](use_probe_xy_offsets.md) — explicit per-section override for whether `ProbePointsHelper`-based probing applies the probe's X/Y offsets, exposed on `[bed_mesh]`, `[bed_tilt]`, `[z_tilt]`, `[quad_gantry_level]`, `[delta_calibrate]`, and `[screws_tilt_adjust]`. Based on Kalico PR #500 by Rogerio Goncalves.
- [**Plugin System**](plugin_system.md) — load extras from `klippy/plugins/` without marking the install dirty; supports both single-file and package-style plugins. Based on Kalico PRs #82 and #100 by Brandon Nance, with package-directory support by Uku.
- [**Log Rotation**](log_rotation.md) — `--rotate-log-at-restart` startup flag and `LOG_ROLLOVER` G-code for explicit log rollover, alongside upstream's midnight rotation. Based on Kalico PRs #181 and #498 by Rogerio Goncalves.
- [**gcode_shell_command**](gcode_shell_command.md) — `[gcode_shell_command <name>]` config sections expose configured shell commands as `RUN_SHELL_COMMAND CMD=<name>` G-code with timeouts, parameter passthrough, and streamed output. Based on Eric Callahan's original extension, brought into Kalico via PRs #71 and #777 by Rogerio Goncalves and Clifford.
- [**Autoload Modules**](autoload_modules.md) — `[force_move]`, `[respond]`, and `[exclude_object]` are loaded by default with `enable_<name>` opt-out keys, removing common boilerplate from `printer.cfg`. Based on Kalico PRs #135 and #306 by Rogerio Goncalves and the respond-default change.
- [**Jinja2 Extensions**](jinja2_extensions.md) — `{% do %}`, `{% break %}`, and `{% continue %}` are enabled in the gcode_macro template environment. Based on Kalico PRs #26 by Morten Lindhardt and #442 by Frank Tackitt.
- [**Auto Reload**](auto_reload.md) — `[auto_reload]` watches `printer.cfg` and triggers `RELOAD_GCODE_MACROS` on save. Original work by Matt Szturc.
- [**Restart Hook**](restart_hook.md) — `~/printer_data/config/scripts/before-restart-klipper.sh` is executed best-effort between klippy restarts. Original work by Matt Szturc.
